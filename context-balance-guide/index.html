Context Balance Guide

Record directly visible details, derived notes, missing context, and the decision boundary — one at a time, without turning a working note into a fact.

Balance each read

A single loud statement can outshout the context it is missing. The context balance keeps the visible side and the missing side apart, so neither drowns out the other.

Directly visible

Record only what the source explicitly shows — a title, a domain, an option name, a price, an image. This is the side you can point to.

Derived note

Write your own working note from the visible content. Label it as yours. A derived note is useful, but it is not a new fact and it does not replace the source wording.

Missing context

Note what is absent — currency, quantity, version, time, source, restrictions. Each absence has weight, even though nothing on the page calls attention to it.

Decision boundary

Mark where you will pause. When the visible side cannot carry the claim being made, the boundary is where you stop rather than balance by assumption.

A worked balance

  1. Directly visible: the page shows a bag with a price.
  2. Derived note: “the price appears to be for the whole bag.”
  3. Missing context: no currency and no quantity are shown.
  4. Decision boundary: pause until currency and quantity are confirmed.

Context example — not a product score, comparison result, recommendation, or verification.
